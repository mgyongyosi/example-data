# Animals

Animals whose names appear in Apple's list of Mac operating system releases,
covering the cat-named sequence from Mac OS X 10.0 through OS X 10.8.
Entries describe the animals as well as their associated releases.
Puma and mountain lion name the same species; panther is a common name
with several biological meanings, not a separate species.

## Mac OS release names

- [Cheetah](Cheetah.md) - A slender, spotted cat that lent its name to Mac OS X 10.0.
- [Puma](Puma.md) - An American cat also called a cougar or mountain lion, namesake of Mac OS X 10.1.
- [Jaguar](Jaguar.md) - A powerful, rosette-marked American cat that lent its name to Mac OS X 10.2.
- [Panther](Panther.md) - A common name used for several cats, associated with Mac OS X 10.3.
- [Tiger](Tiger.md) - A large Asian cat that lent its name to Mac OS X 10.4.
- [Leopard](Leopard.md) - An adaptable, rosette-marked cat that lent its name to Mac OS X 10.5.
- [Snow leopard](Snow%20leopard.md) - A mountain-dwelling Asian cat that lent its name to Mac OS X 10.6.
- [Lion](Lion.md) - A large cat of Africa and India that lent its name to OS X 10.7.
- [Mountain lion](Mountain%20lion.md) - Another name for the puma, used for OS X 10.8.
