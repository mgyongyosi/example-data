# Panther

Panther is a common name, not the name of a single species. A black panther
can be a melanistic [leopard](Leopard.md) or [jaguar](Jaguar.md), whose dark
coat does not make it a separate species.[^leopard][^jaguar]

The name also appears in Florida panther, a population of
[*Puma concolor*](Puma.md). Because the word has several uses, a scientific
name should be supplied when identifying a particular animal.[^puma]

## Mac OS namesake

Panther is the name associated with Mac OS X 10.3. Apple's release listing
does not identify it as a distinct biological species.[^macos]
